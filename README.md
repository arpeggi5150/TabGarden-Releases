# TabGarden releases

Prebuilt Windows builds of TabGarden, a guitar tab player and editor: open Guitar Pro files (.gp, .gp5, .gpx),
play, loop, slow down, edit fret numbers and save as .gp (opens in Guitar Pro 7 and 8).

Download from **Releases**. `TabGarden-x.y.z-portable.exe` runs without installing.
The builds are not code-signed yet, so Windows SmartScreen asks first: More info, then Run anyway.
